# Community Counselors

Repositório estratégico da **Community Counselors** — comunidade fechada para founders cristãos da Geração Z que integra fé e empreendedorismo.

---

## O que é este repositório

Centraliza o material estratégico, discurso, KPIs e planejamento operacional da comunidade.

---

## Estrutura


## Agentes disponíveis

| Comando | O que faz |
|---|---|
| `/planejamento-estrategico` | Panorama geral do mês, KPIs e ajustes de rota |
| `/planejar-semana` | Monta o planejamento semanal dia a dia |
| `/status-membros` | Atualiza o status de cada membro fundador |

## Os 3 Pilares

1. **Vocação** — Empreender é uma chamada, não só uma escolha
2. **Propósito** — Conectar o negócio a algo maior que o lucro
3. **Mordomia** — Gerir bem o que foi confiado
