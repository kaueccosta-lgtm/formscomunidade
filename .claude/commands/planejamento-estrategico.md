# /planejamento-estrategico

Agente de planejamento estratégico da Community Counselors.

Ao ser invocado:

1. Leia o CLAUDE.md para ter o contexto completo
2. Leia o arquivo `estrategia/kpis.md` para ter os KPIs por horizonte
3. Apresente o panorama geral do mês: status dos membros, tarefas concluídas, tarefas pendentes
4. Identifique o que está atrasado ou em risco
5. Sugira ajustes no planejamento se necessário
6. Pergunte se o usuário quer atualizar o status dos membros ou os KPIs

**Estrutura de planejamento:**
- Fim de semana: revisar o que aconteceu na semana + planejar a próxima
- Fim do mês: revisar metas, atualizar status, definir foco dos próximos 3 meses
