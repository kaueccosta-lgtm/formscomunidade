# /status-membros

Agente de atualização de status dos membros fundadores.

Ao ser invocado:

1. Leia o CLAUDE.md para ver a lista atual de membros
2. Apresente a tabela de status atual
3. Pergunte o que mudou desde a última atualização
4. Atualize a tabela com os novos status
5. Identifique a próxima ação para cada pessoa
6. Atualize o CLAUDE.md com os novos status
7. Pergunte se quer atualizar também no Notion (CRM)

**Status possíveis — Convite:**
- Não contatado
- Convidado (aguardando resposta)
- Follow-up enviado
- Aceitou ✓
- Recusou

**Status possíveis — Entrevista:**
- Pendente
- Agendada (data: __)
- Realizada ✓

**Fluxo após aceite:**
- Enviar onboarding
- Agendar entrevista de pesquisa (exceto quem já está na comunidade)
- Pedir indicações de outros founders cristãos
